[center][size=6][b]Version 1.3.0[/b][/size][/center]

[size=5][b]New Features[/b][/size]

[b]Ranged Damage Multiplier[/b]
- Added [b]UnitRangedDamageTakenMultiplier[/b] - Global multiplier for all ranged damage (Arrow, Bolt, Slinger, Javelin)
- Works in real-time during gameplay

[b]Structure Damage Multipliers[/b]
- [b]WallDamageTakenMultiplier[/b] - Now properly detects and applies to walls (stone and crenel walls)
- [b]TowerDamageTakenMultiplier[/b] - Multiplier for all tower levels
- [b]CivilStructureDamageTakenMultiplier[/b] - Multiplier for civilian structures (replaces WoodenStructureDamageTakenMultiplier)
- All structure multipliers stack with the global StructureDamageTakenMultiplier

[b]Wall Cost Multipliers[/b]
- [b]LowWallCostMultiplier[/b] - Controls cost for low/short walls (default: 0.25)
- [b]HighWallCostMultiplier[/b] - Controls cost for high walls and crenel walls (default: 0.5)
- Note: Wall costs are now controlled via multipliers in the BepInEx config, not TOML

[b]Improvements[/b]
- Refactored BepInEx config system for better organization
- Improved structure categorization and detection
- Better error handling and validation

[size=5][b]Known Issues[/b][/size]

[b]Speed Property Limitation[/b]
- Some units (animals, special units like RABBIT, CAMEL, CROW, etc.) cannot have their Speed modified due to a limitation in the SHCDE-SE API
- The speed array only contains data for the first ~45 unit types
- These units will show Speed in the config file, but attempting to modify them will log warnings
- This has been reported to the SHCDE-SE author

[size=5][b]Important: Updating[/b][/size]

[b]Delete your old config files[/b] when updating. If you want to keep your changes, manually add them back to the new config files.

Config location: [b]BepInEx/config/[/b]
