# Test card 2.11.9: host plays what it sent; simulation version check (GitLab #15, FWP-E-04, FWP-E-09)

Two PCs (PC-A hosts, PC-B joins), both 2.11.9 (same hashes) unless a step says otherwise.

1. PC-A: start the game with `[CHIMP_TYPE_SPEARMAN] Health = 500` in its Units file. Open a lobby, sync ON.
   PC-B joins. Expected PC-B log: `Received the host's configs ... host v2.11.9+sim1. Verified OK.`, `Applied the host's configs`.
2. Without restarting, PC-A edits its Units file to `Health = 50`. Start the match.
   Expected PC-A log: `Your config files changed since the game started ...` and `Hosting with config sync on ...:
   you play the files you sent`. A Spearman has 500 health on BOTH PCs. No out-of-sync over 10 minutes.
3. After the match PC-A leaves the lobby and starts a single-player skirmish. Expected PC-A log: `You are no longer
   hosting` or `Not hosting with config sync any more`; a Spearman has 50 health (PC-A's live file).
4. PC-A runs 2.11.2 and hosts, PC-B runs 2.11.9 and joins (same major.minor). Expected PC-B log: `REJECTED the host's
   configs: ... do not play the same files the same way (simulation version host unknown, before 2.11.9, you 1)`;
   PC-B's tab status says "these play differently". (From 2.11.11 the Script Extender may refuse this join first,
   since the mod then declares NetworkMode 1; that is also a pass.)

PASS = all expected results, no desync in step 2. Attach both LogOutput.log files (grep `[ConfigSync]`).
