Version 2.7.1 - requires Script Extender 2.8.0 or newer

[h1]Getting Started[/h1]
[h2]1. Install[/h2]
[list]
[*]Needs [url=https://www.nexusmods.com/strongholdcrusaderdefinitiveedition/mods/36]BepInEx 5 Bootstrapper[/url] and [url=https://www.nexusmods.com/strongholdcrusaderdefinitiveedition/mods/35]Script Extender[/url] [b]2.8.0 or newer[/b].
[*]Subscribe, then launch the game once and go to the main menu. This creates the config files in [b]<game folder>\BepInEx\config\CrusaderDETweaker\[/b].
[*]Check it worked: BepInEx\LogOutput.log contains "Loading [Crusader DE Tweaker ...]" and "ALL 6 TEST SUITES PASSED". "missing dependencies: 000shcdese" means the Script Extender is not installed.
[/list]

[h2]2. Your first change: make Knights cost 5000 gold[/h2]
[list]
[*]Open [b]CrusaderDETweaker_Units.toml[/b] in a text editor (Notepad works).
[*]Find [b][CHIMP_TYPE_KNIGHT][/b] and the line [b]GoldCost = -1 # Default: 40[/b].
[*]Change only the number: [b]GoldCost = 5000 # Default: 40[/b]. Keep the [b]#[/b]: everything after it is a comment, and a line without it is a syntax error that makes the game ignore the whole file (the log then says "SYNTAX ERROR" with the line number).
[*]Save, restart the game, start a skirmish and recruit a Knight: it now costs 5000 gold.
[/list]
[b]-1[/b] means "use the game's value". Put -1 back to undo a change, or delete a config file to regenerate it with defaults.

[h2]3. What you can change[/h2]
[list]
[*][b]CrusaderDETweaker_Units.toml[/b]: per unit Health, Speed (0 to 6, lower is faster), gold cost, weapon / armour / horse requirements ("NONE" = gold-only hire), shield health, run-speed bonuses, MaxCount (cap on how many you can have).
[*][b]CrusaderDETweaker_Structures.toml[/b]: per building health, costs, housing, MaxCount.
[*][b]CrusaderDETweaker_GameplaySettings.toml[/b]: siege-engine stones, stealth, gates, trade prices, auto-trade, gameplay options. Applied at every game start and save load.
[*][b]DamageMatrices\*.csv[/b]: damage per attacker and defender (melee, ranged, eunuch, ballista, fire, Bedouin healing, building fire). Rows are defenders, columns are attackers; -1 leaves the game value.
[*][b]CrusaderDETweaker_GlobalMultipliers.cfg[/b]: global multipliers (health, damage taken, wall costs...), most apply without a restart.
[/list]

[h2]4. Multiplayer: the host's settings for everyone[/h2]
When the host has "Players who join use my configs" on (default) in the lobby's Mod Options window, tab "Crusader DE Tweaker", every player receives the host's config files and multipliers for that match. Your own files are never changed; they apply again when you leave. Host and players need the same 2.7.x version.

[h2]5. Updating[/h2]
Steam updates the mod for you. Your config files are kept: the mod never resets your values, it only adds new settings on launch.
